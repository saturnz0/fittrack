# FitTrack V1

PWA mobile-first de acompanhamento de academia.

## Como testar
Abra `index.html` em um navegador moderno. Para recursos PWA completos (instalação/offline), sirva a pasta por HTTP/HTTPS.

Exemplo:
`python -m http.server 8080`

Depois abra `http://localhost:8080`.

- Treinos A/B/C/D
- Registro de séries e cargas
